- 画面：`/guide`

目的は「配置を変えると、同じタイトル・同程度の人数・同じ時間での収入がどう変わるか」を短時間で理解できること。網羅的な設定辞典にはしない。

## 画像の更新

匿名のローカルD1で撮影する。本番の組織・氏名・会員ID・明細・口座情報を使わない。今回の山田さんは初期マイグレーションにある架空サンプル。

1. 現行UIで計算完了を確認する。
2. 概要、移動先選択、A/B比較、金額内訳、保存一覧の5場面を撮影する。
3. 画像中のボタン名・数値と本文・キャプションを照合する。
4. 画像差し替え後にビルドし直す。画像は静的アセットとして配信される。
5. PC・390px幅で画像の読み込み、画像拡大、目次、試算画面へ戻る導線を確認する。

比較画像は同じ120か月・509 IDの例。配置前433,112円、配置後436,042円、差額2,930円。TRD達成の例ではなく、同じ時間での比較操作を示すもの。

マニュアルはデータ読込APIを呼ばないため、組織データが読み込めない場合にも操作説明を開ける。スクリーンショットの金額は利用者の試算結果と明確に区別する。
